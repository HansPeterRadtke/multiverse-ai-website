FEATURED OPEN-SOURCE PROJECT · SWAAG

Your AI can answer questions. Can it handle the work?

SWAAG is software for developers who want to connect an AI model with real programs, files and other tools. Its aim is to provide the agent infrastructure needed to manage tasks with multiple steps and preserve evidence of what happened.

THE SITUATION

Your engineering team runs a local AI model. A useful task needs more than a chat response.

Imagine asking an assistant to help investigate a software change. The work may involve examining files, using permitted developer tools, running tests, analyzing errors and reporting the outcome. A language model alone does not provide reliable access, coordination or durable task records.

Intended users: developers and engineering teams building their own AI-enabled workflows. Illustrative use case, not a claimed customer deployment or a proven autonomous code-change demonstration.
THE INFRASTRUCTURE SWAAG PROVIDES
1

One entry point for the taskA persistent orchestrator decides whether and how substantive work needs workers.

2

Workers with configured tool accessAgent workers can call permitted capabilities, including external integrations, instead of merely describing actions.

3

Inspectable state and progressDurable events, task state and recovery mechanisms provide a basis for seeing what happened and checking work.

WHY THIS MAY BE USEFUL

Start with an agent foundation rather than building the infrastructure from zero.

For teams already running local models, SWAAG offers implemented building blocks for tool orchestration, long-lived work and task records. That could make developing a controlled AI workflow more practical, but real results depend on the connected models, tools and tests.

WHAT MAKES IT WORTH INSPECTING?

The implementation is public.

Read the source, setup manual and tests instead of relying on marketing promises. SWAAG is MIT-licensed open-source software; the code is available free under that license, and it is not being advertised as an exclusive product for sale.

Current status

A real, evolving developer framework—not a turnkey employee, a ready-made corporate deployment or a guarantee of reliable unattended task completion.

No verified customer time savings, benchmark superiority or enterprise certification is claimed.

01 / PUBLISHED SOFTWARE · FOR WIX STORE OWNERS

Late Order Monitor — an app for managing existing shop orders.

For businesses that operate an online shop using Wix Stores. When customers place orders in that shop, the owner needs to know which paid orders have not been shipped yet. This separate, read-only app displays those orders, helps identify older ones, and lets the owner export a follow-up list.

02 / AI PROJECT · DOCUMENT ANSWERS WITH SOURCES

KnowMoreDiRT — ask questions about your documents.

Imagine you have many folders of reports, notes, logs and transcripts. Instead of opening files one by one, the goal is to point KnowMoreDiRT at a folder, ask a question in everyday language, and receive a short answer. The system keeps source evidence internally so results can be investigated rather than blindly trusted.

So far, this page shows evidence from a limited test using fictional documents. It is not a production-ready search service or an AI system running new queries directly on this website.

What has actually been tested?

A controlled one-file experiment returned the expected answer and identified the supporting text. The system used local models and cached intermediate results. That does not establish general performance across real company document collections.
