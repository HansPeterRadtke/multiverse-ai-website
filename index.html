SWAAG · SELF-HOSTED AUTONOMOUS AGENT FRAMEWORK

Keep talking to your assistant. Let the workers do the work.

With SWAAG, the intended experience is one persistent assistant acting as a team leader. It delegates longer work to background agents, coordinates independent and dependent tasks, and keeps their state and history available when you return.

THE USER'S PROBLEM

Why should you have to supervise every agent individually?

Imagine several software projects needing investigation, tests, documentation and follow-up. You want to ask what is running, add another job, change priorities, or stop one worker without losing the progress of the others.

The goal is to manage outcomes from one conversation, not babysit a collection of agent windows. Illustrative use case. A fully autonomous 24/7 deployment and measured saved operator time are not claimed.
THE ORCHESTRATED WORKFLOW
1

One responsive conversationThe persistent user-facing orchestrator answers status questions and receives new instructions while workers have their own lifecycles.

2

Workers and dependenciesSeparate jobs can be delegated, scheduled, run concurrently where resources permit, and connected when one result is needed by another.

3

Durable memory and controlSource events, task status, notes and context projections support inspection and recovery without relying only on the model's current context window.

THE PRACTICAL BENEFIT

Stay available for decisions while the detailed work continues.

Inspect a worker's progress, reprioritize a task or ask another question without treating each worker as a separate chatbot. SWAAG's event records also provide a basis for history analysis, notes and contextual recall instead of losing everything when a model context fills up.

CONTINUATION, WITH USER CONTROL

Approved work can persist beyond one conversation.

Durable worker plans and wakeups support authorized backlogs and an optional autonomous-continue mode. Those modes are deliberate configuration choices; automatic background dispatch is disabled by default. Notes, history analysis and self-improvement are ongoing engineering objectives, not guaranteed unattended services.

Implementation and current boundaries

SWAAG is a real MIT-licensed, local-first Python framework with public orchestrator, worker, scheduler and history code. It remains an evolving developer system: the quality of any autonomous result depends on the models, permissions, tools, configuration and verification.

No claim of universal reliability or tested superiority over Codex, Claude Code, Dots or other agent frameworks.

FLAGSHIP RESEARCH · SOURCE-GROUNDED KNOWLEDGE

KnowMoreDiRT — find meaning in the file chaos.

Company knowledge hides in badly named files, deeply nested folders, inconsistent logs and outdated reports. A search match is not necessarily true in the requested context. KnowMoreDiRT combines file metadata, source-linked text and semantic retrieval with Discourse Representation Theory (DRT) to track referents, dates, claims and the conditions in which they apply. The goal is to find relevant information efficiently and reason across it without losing its meaning.

So far, this page shows evidence from a limited test using fictional documents. It is not a production-ready search service or an AI system running new queries directly on this website.

RESEARCH PROTOTYPE · NOT FOR SALE AS A FINISHED APP

What has actually been tested?

A controlled one-file experiment returned the expected answer and identified the supporting text. The system used local models and cached intermediate results. That does not establish general performance across real company document collections.

PUBLISHED WIX APPLICATION · ORDER OPERATIONS

Late Order Monitor — an app for managing existing shop orders.

For businesses that operate an online shop using Wix Stores. When customers place orders in that shop, the owner needs to know which paid orders have not been shipped yet. This separate, read-only app displays those orders, helps identify older ones, and lets the owner export a follow-up list.

A SMALL PUBLISHED PYTHON TOOL · ON PYPI

Captain Obvious — CapOv

Fix simple, mechanical Python mistakes without asking an AI agent to rewrite your program. CapOv can clean up duplicate imports, add certain missing imports and repair selected bracket errors. Ruff already automates many Python fixes; CapOv is a smaller, simple CLI utility rather than a replacement for a full linter. Review edits before use.
