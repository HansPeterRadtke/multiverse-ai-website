FEATURED PROJECT · OPEN-SOURCE AI AGENT FRAMEWORK

When an AI assistant needs to do more than chat.

SWAAG is a local-first framework for building AI agents that can use tools, coordinate substantial tasks and keep a durable record of what happened.

WHEN WOULD YOU NEED IT?

You run an AI model, but the work also involves files, programs and many steps.

For example, a developer wants an assistant to inspect project files, use permitted commands or APIs, run checks and report what succeeded. A chatbot answering questions alone does not provide the entire workflow.

For developers, technical teams and builders of private AI tools.
WHAT SWAAG PROVIDES
1

Describe a taskA persistent controller handles the conversation instead of forcing the user to manage separate agents.

2

Use tools and workersConfigured capabilities can interact with files, software tools and specialized task workers.

3

Inspect progress and resultsDurable history and task state support progress reporting, recovery and verification.

What could this help you build?

A tool-using AI assistant without writing orchestration, task history and worker management from scratch. Its local-first design can suit teams running their own models and tools.

Real open-source implementation; still in development. No promise of unattended production reliability, guaranteed time savings or suitability for every organization.

01 / PUBLISHED SOFTWARE · FOR WIX STORE OWNERS

Late Order Monitor — an app for managing existing shop orders.

For businesses that operate an online shop using Wix Stores. When customers place orders in that shop, the owner needs to know which paid orders have not been shipped yet. This separate, read-only app displays those orders, helps identify older ones, and lets the owner export a follow-up list.

02 / AI PROJECT · DOCUMENT ANSWERS WITH SOURCES

KnowMoreDiRT — ask questions about your documents.

Imagine you have many folders of reports, notes, logs and transcripts. Instead of opening files one by one, the goal is to point KnowMoreDiRT at a folder, ask a question in everyday language, and receive a short answer. The system keeps source evidence internally so results can be investigated rather than blindly trusted.

So far, this page shows evidence from a limited test using fictional documents. It is not a production-ready search service or an AI system running new queries directly on this website.

RESEARCH PROTOTYPE · NOT FOR SALE AS A FINISHED APP
WHAT YOU DOChoose a folder and ask a question.Current interface: two Python functions, not a finished web app.
WHAT IT AIMS TO SAVETime searching through scattered files.Intended benefit; large real-world collections are not yet validated.
WHY IT MAY BE MORE TRUSTWORTHYThe answer has source records behind it.Evidence stays inside the system; public API still returns plain text.
DOCUMENTSA collection of files containing facts

What has actually been tested?

A controlled one-file experiment returned the expected answer and identified the supporting text. The system used local models and cached intermediate results. That does not establish general performance across real company document collections.
