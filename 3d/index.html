THE TECHNOLOGY BEHIND THE IMAGES

I built the pipeline. AI agents run the tools.

This is a custom production workflow using my own machines and software—not an account on a one-click 3D generation service. ChatGPT-assisted and locally hosted AI agents can coordinate development and review tasks while Blender and Python perform the concrete engineering work.

01 / PLAN & DIRECT

Translate a product goal into jobs.

Agents work from asset requirements, study industrial references, propose geometry, materials, cameras and mechanical motion, and prepare scripts or tasks for the next step.

02 / BUILD IN BLENDER

Create editable geometry and animation.

Blender/Python constructs machinery, racks, industrial rooms and moving parts. Material pipelines build PBR maps and scene lighting; native .blend projects remain editable.

03 / RENDER & INSPECT

Test the work across machines.

Rendering and verification operate on available systems. Image and video analysis, source inspection, collision and geometry checks help identify problems before a new revision.

04 / EXPORT & VALIDATE

Package real usable model files.

Automated checks exercise GLB/glTF and other supported formats, clean reimports, animation and scene integrity. Marketplace packaging is a distinct final step, not proof of photorealism.

The agents automate substantial authoring and evaluation work. That does not imply every decision is made without human input, that every scene is photorealistic, or that every export already meets all engine and marketplace requirements.

WHY THIS MATTERS BEYOND 3D MODELS

AI doing production work—not just producing suggestions.

The same engineering method applies to other defined software tasks: an agent receives an objective, uses real applications through tools, produces artifacts, runs repeatable checks and records what passed or failed. The 3D pipeline is a tangible demonstration of that capability, with visible products rather than an abstract agent diagram.

Owned infrastructure. Blender, Python, models and validation tools operate on local machines under direct control.

Multi-step execution. Geometry, texturing, animation, rendering, testing and packaging are connected workflows.

Reproducible evidence. Scenes, scripts, source renders and validation receipts enable technical inspection instead of relying on screenshots alone.

Honest quality gates. Commercial acceptability and photographic realism are separate assessments; visual defects remain open where not yet resolved.

CUSTOM MULTI-MACHINE SETUP

Different tools, different machines. One production workflow.

Nitro · Blender and Python

Builds geometry, materials, exports and independent visual and file checks from reproducible project scripts.

Thor · Heavy AI and rendering

Runs larger local models and supports demanding rendering or visual-computation work where capacity allows.

Jetson · Visual analysis

Local vision-model experiments inspect animation contact sheets and report findings about candidate outputs.

Raspi · Shared coordination

Provides infrastructure documentation, project exchange and resource-broker controls so different workers do not blindly compete for hardware.

Agent tools and human-reviewed ChatGPT workflows coordinate parts of this production. These are documented system roles, not a claim that a single unified job automatically runs every stage on every host.
