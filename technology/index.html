SWAAG · OPEN-SOURCE AI AGENT RUNTIME

Already running an AI model? What if it needs to use your tools?

SWAAG is a framework for developers building assistants that work with software tools, coordinate multi-step tasks and preserve inspectable task state. It is a starting point for an integration, not a ready-to-use business assistant.

VERIFIED RESEARCH TEST · NOT A FINISHED PRODUCT

KnowMoreDiRT: ask questions about existing files

The problem: useful information is scattered across many reports, notes and log files. Searching manually is time-consuming.

The intended workflow: point KMD at an existing folder of readable text, ask a question in normal language, and receive a plain answer. Source context is held internally so the result can be investigated. This could reduce manual searching, but the benefit is not yet validated at business scale.

See the limited fictional test

Test question: Who reviewed the Falcon Test Plan?

Test answer: Mira Chen — a made-up person in a fictional document, not a Multiverse employee.

Original fictional file: Mira Chen reviewed the Falcon Test Plan on 12 November 2026..

This proves one bounded, model-verified test on a fictional one-file corpus, not broad production reliability or a live new query on the website.

AI agent platformOpen-source development

SWAAG

An AI agent that can carry out computer tasks instead of only answering questions.

Why it matters: Explore automating multi-step tasks while keeping control of tools and local infrastructure.

How it works: Give the assistant a request. Its controller can choose tools and specialized workers, track the task, and return results.

Current limitations

An actively developed framework, not a finished hands-off consumer assistant.

File & data toolsPublic Python tool

all2text

Convert folders of different file types into auditable plain-text outputs.

Why it matters: Prepare material for search, migration audits, or AI ingestion without losing track of which formats were unsupported.

How it works: Point the tool at a folder. It mirrors the directory structure and produces text files and a conversion manifest.

Current limitations

Some formats require optional converters; it records limitations rather than inventing extracted content.

Android keyboardWorking prototype · source not yet public

KontextTastatur

A German-English keyboard that learns from words the user confirms.

Why it matters: Explore more relevant suggestions while keeping personal typing history on the device.

How it works: Type normally, choose a suggested word or phrase, and let local word-frequency history influence later suggestions.

Current limitations

Current implementation lives in a development worktree. It is not in the public Android repo or a verified Play Store release.
