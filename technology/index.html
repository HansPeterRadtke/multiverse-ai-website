TECHNOLOGY

Engineering systems
that do real work.

Independent exploration and development across AI automation, private language models, knowledge intelligence and robust software engineering.

01 / AUTONOMOUS SYSTEMS

Autonomous agents and workflow automation

Systems that connect AI reasoning with applications, browser interactions, command-line tools and APIs. Engineering priorities include task verification, error handling, resource coordination and recoverability.

Examples: multi-machine tool orchestration, browser-assisted processes and local voice-agent infrastructure. These are engineering projects; suitability for a customer's environment would require a defined evaluation.

02 / PRIVATE INTELLIGENCE

Language models and source-grounded knowledge

Local model inference and knowledge retrieval that maintains references to original documents. Useful starting points for organizations that need answers across large, messy document collections or prefer local control over AI components.

Example: KnowMoreDiRT, a research and engineering system for source-grounded document retrieval. Not presented here as a commercially certified deployment.

03 / SOFTWARE & DATA

Automation, integration and rigorous validation

Over twenty years of software engineering experience inform the design of complex systems, C++ and Python tools, automated tests, data processing and algorithm evaluation.

Examples include automated data validation, software integration workflows and the separately published Late Order Monitor for Wix Stores.

What is available? Technology ranges from experimental prototypes to published applications. Commercial readiness, scope, intellectual-property terms and handover requirements are established separately for each opportunity.
