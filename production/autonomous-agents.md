# Autonomous AI agents — verified multi-step workflow demonstration

Target: 85–110 seconds plus an 8–15-second muted teaser. Status: **script and capture plan**, not recorded proof.

## Goal and test scenario

Show a real agent completing a safe multi-application or browser process. Preferred scenario: read **synthetic test** order records or a public test document, process/reconcile information, update an owned test spreadsheet or issue tracker, save a verifiable report, and check it. Do not allow real orders, user mail, finance or account changes. Use an independent test browser, never the owner's ongoing one-tab AUBRO sender. If a separate test environment is unavailable, use local test applications.

## Storyboard

| Time | Real screen capture | Narration |
|---|---|---|
| 0–8s | Title card “A task that spans several tools” plus real test process diagram | “Complex office work rarely happens in a single application.” |
| 8–20s | Show concrete user instruction and boundaries (test-only) | “Here's a defined task: collect information, perform the steps and confirm the result.” |
| 20–50s | Continuous real footage: agent reads input, invokes browser/API/tools, and updates test artifact. Speed up only with honest time indicator | “The agent coordinates the applications and performs the steps under defined permissions.” |
| 50–72s | Verify saved report against original; screen shows actual test assertions or output checks | “An action is not complete just because it was attempted. We inspect and verify the output.” |
| 72–92s | Inject a controlled recoverable error, or show existing real error and subsequent genuine recovery; do not pretend failures were recovered without tests | “Real automation needs to handle interruptions and unexpected states. Here is a controlled test of that behavior.” |
| 92–110s | Concise result, boundaries, CTA “Discuss a business problem” | “The right automation begins with a concrete business process and clear acceptance criteria.” |

Do not show raw chain-of-thought or private credentials. A readable action/result log is fine. Document agent commit/version, model, tools, input, acceptance criteria, time, exact outputs and whether recovery was really tested. Avoid promising autonomous universal work or financial savings without measured evidence.

## Homepage teaser

Real task → real agent action → saved verified test artifact → “MULTIVERSE · VERIFIED AUTOMATION.” Overlay factual labels only, not generated screenshots posing as source footage.
